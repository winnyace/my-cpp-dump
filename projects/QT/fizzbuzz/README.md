# FizzBuzz

This is a simple QT app that takes a numeric input from the user and plays the game [Fizz buzz](https://en.wikipedia.org/wiki/Fizz_buzz), returning "fizz" if the input is divisible by three, "buzz" if the input is divisible by 5, "fizzbuzz" if the input is divisible by 3 and 5 or the input if it doesn't match any previous case.
